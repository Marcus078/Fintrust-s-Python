# Week 1 Overview

Week 1 introduced the foundations of both Cloud Computing and SQL Databases. Throughout the programme, all learning is based on a single evolving case study, **FinTrust Bank**, a South African digital bank that is modernising its systems by moving from on-premises infrastructure to AWS.

As we progress through the programme, every topic we learn will contribute to designing and building FinTrust's cloud-native transaction intelligence platform.

---

## FinTrust Bank Scenario

FinTrust Bank serves over 2 million customers across South Africa and is facing challenges related to growth, compliance, fraud detection, and system performance.

Throughout the programme, we will progressively design and build solutions to help FinTrust:

- Scale its systems to support future growth
- Meet POPIA compliance requirements
- Improve transaction processing performance
- Implement real-time fraud monitoring
- Migrate from traditional infrastructure to cloud-native services

The main business entities introduced during Week 1 were:

- Customers
- Accounts
- Transactions

These entities form the foundation of the FinTrust database used throughout the programme.

---

## AM Sessions: Cloud Computing Fundamentals

During the morning sessions, we focused on the foundations of cloud computing and AWS.

Topics covered included:

- Introduction to cloud computing
- Benefits of cloud adoption
- Cloud service models
- AWS Global Infrastructure
- AWS Regions
- Availability Zones (AZs)
- Edge Locations
- Shared Responsibility Model
- FinTrust cloud architecture scenario

These sessions helped build an understanding of how AWS infrastructure supports secure, scalable, and highly available applications.

---

## PM Sessions: SQL Fundamentals

During the afternoon sessions, we worked with SQL and MySQL Workbench.

Topics covered included:

- Installing and configuring MySQL Workbench
- Database fundamentals
- Creating tables
- Inserting data
- Building the FinTrust database schema
- Understanding primary and foreign keys
- Writing basic SELECT queries
- Retrieving and sorting data

These practical exercises introduced the database skills needed to manage and analyse FinTrust's customer, account, and transaction data.

---

## Reflection

Week 1 laid the foundation for the rest of the programme. The morning sessions introduced the AWS and cloud concepts that support modern applications, while the afternoon sessions provided hands-on experience working with relational databases and SQL. Together, these topics established the core knowledge required for building cloud-based solutions.

---

## Looking Ahead

Week 2 builds on these foundations by introducing more AWS services and more advanced SQL concepts. We will continue developing the FinTrust solution while learning how cloud infrastructure, databases, and future Python applications work together in a real-world banking environment.
