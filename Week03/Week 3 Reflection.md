## Week 3 Reflection

For FinTrust's compliance archive, I would choose Amazon S3 because it provides durable, scalable, and cost-effective storage for large volumes of compliance and audit records. S3 also supports lifecycle policies and long-term archival options, making it suitable for regulatory data retention requirements.

The hardest Python concept for me this week was error handling and logging. Understanding when to use specific exceptions, implementing try/except blocks correctly, and creating useful log messages required careful attention to detail.

The first skill I would apply on a real project is building reusable Python modules and utility functions. Creating functions that can be imported across multiple scripts improves code organisation, reduces duplication, and makes applications easier to maintain.
