# AWS Solutions Architect Associate Portfolio

## Overview

This repository contains my coursework, labs, architecture designs, Python projects, SQL exercises, and portfolio deliverables completed during the AWS Solutions Architect Associate (SAA-C03) training programme.

The programme combines four learning streams:

- AWS Cloud Architecture
- SQL
- Python
- Git & Portfolio Development

A recurring case study, **FinTrust Bank**, was used to design, document, and justify real-world AWS solutions throughout the programme.
